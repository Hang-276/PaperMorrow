我一直想要一个更连贯的研究工作台：它不只是收藏 PDF，也不只是提供一个聊天框，而是把论文发现、精读、证据、笔记、项目、实验、DDL、PPT 与 AI 协作真正连接起来。没有找到完全符合自己习惯的工具，于是便边学边做了 PaperMorrow。

## PaperMorrow 是什么

PaperMorrow 是一款本地优先的桌面研究工作台。它以项目为中心组织论文、笔记、实验和研究产物，让资料从“收集起来”继续走向“读懂、验证、关联和表达”。

应用会尽量区分论文事实、作者主张、个人记录与 AI 推断。引用论文内容时保留证据来源；只有摘要时会明确标注“仅摘要”，避免把未经验证的内容包装成结论。

## 核心体验

### AI 协作

选择论文、文件或文件夹并描述目标，PaperMorrow 会生成可编辑计划，持续展示执行步骤、资料来源、工具调用、审批请求与最终产物。主 Agent 可以按需委派文献证据、研究综合和项目规划等专家，但每个专家只能获得完成当前任务所需的最小资料与工具权限。

- 支持暂停、继续、取消、单步重试与检查点恢复。
- 文件访问默认拒绝，只能在用户授权的范围内进行。
- 写入、覆盖、批量导入和外部操作需要预览与确认。
- 内置科研 Skill，并可在导入前查看来源、许可证、版本和所需权限。
- 页面内“问 AI”只读取当前可见内容，不会默认扫描全部资料。

### 论文发现与证据化阅读

- 支持广度推荐、方向聚焦和“聚焦 + 探索”混合推荐。
- 聚合 arXiv、Semantic Scholar、OpenAlex、Crossref、PubMed 和 Europe PMC 等学术来源。
- 使用 DOI、arXiv ID、Semantic Scholar ID 与标题指纹进行持久去重。
- 支持中英文摘要与按需分析，并明确标记摘要级证据。
- PDF 阅读器支持懒渲染、划词翻译、提问、引用及插图写入笔记。

### 项目、实验与知识关系

- 每个项目拥有独立的论文队列、项目笔记、专题调研、实验时间线和 AI 检索范围。
- 证据化知识关系按项目分别建立，并保存来源、证据和置信度。
- 实验分析通过实验编号关联配置、指标、观察与产物。
- DeepWiki 将仓库结构、关键模块和源码证据整理为本地 Wiki，无需执行第三方仓库代码。

### 笔记、PPT 与研究产物

- 统一管理论文笔记与独立笔记，支持 Markdown、LaTeX、可视化编辑和源码编辑。
- 从可编辑大纲生成 `.pptx`，并保留论文、笔记和实验来源。
- Cowork 产物区集中管理报告、表格、PPT、笔记与导入论文。
- LLM 调用记录只保存用途、模型和 Token 数量，不保存提示词正文、回复正文或 API Key。

## 本地优先

数据库、API Key、论文、PDF、笔记、Wiki、项目和实验记录默认保存在本机。PaperMorrow 使用 SQLite、FTS5 与 BM25 进行本地检索，不要求独立向量数据库、云端账户或常驻远程服务。

模型 API 只会在主动使用 AI 功能时调用，界面会说明发送范围。未配置 API Key 时，论文库、项目、笔记、实验记录、DDL、基础检索和本地整理功能仍可使用；依赖模型的功能会明确暂停或降级，不会伪造执行结果。
